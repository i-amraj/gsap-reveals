# 🎨 Style 5.3: Dynamic SVG Vector Path Drawing (`17_svg_path_drawing_scroll`)

This library provides 22 variations of SVG path drawing animations. These modules focus on animating SVG `stroke-dashoffset` and `stroke-dasharray` natively with GSAP ScrollTrigger to simulate lines drawing themselves.

## 🚀 How to Use
Navigate into any sub-directory and open `index.html` in your browser. Each directory contains a `prompt.md` which you can use to generate this exact effect in any AI.
