# ThreeJS 3D Cube Scroll
Integrates WebGL (Three.js) with GSAP. A 3D scene is set to `position: fixed` behind the HTML layout. As the user scrolls through HTML `<section>` steps, ScrollTrigger scrubs GSAP tweens applied to the Three.js mesh's `.position`, `.rotation`, and `.scale` properties, proving you can animate 3D space with the same API.
