# 🌟 Project 7.1: AI Super Skill Library (`22_ai_super_skill_library`)

This is the ultimate reference library for the AI. It contains advanced, Awwwards-level snippets combining GSAP with WebGL (Three.js), Canvas, Lottie, and complex math.

| # | Module | Core Technique | Status |
|---|---|---|---|
| 01 | `lottie_scroll_trigger` | Syncing Adobe AfterEffects Lottie JSON animations to GSAP ScrollTrigger. | ✅ |
| 02 | `emoji_cursor_trail` | Physics-based particle trail mapping arrays to mouse movement. | ✅ |
| 03 | `magnetic_button` | Mouse-move distance calculation for a sticky UI magnetic pull. | ✅ |
| 05 | `threejs_3d_cube_scroll` | Using GSAP to animate a WebGL Three.js camera and mesh on scroll. | ✅ |
| 06 | `webgl_image_ripple` | Three.js shader material dynamically updated by GSAP hover state. | ✅ |
| 07 | `custom_cursor_blend_mode` | Custom cursor with `mix-blend-mode: difference` tracking with `quickTo`. | ✅ |
| 08 | `split_text_wave_animation` | `stagger` and `yoyo` applied to individual characters for a wave effect. | ✅ |
| 09 | `svg_gooey_button` | Combining SVG matrix filters and JS-spawned bubbles for a liquid click. | ✅ |
| 10 | `infinite_marquee_scroll` | Seamless looping marquee whose speed responds to scroll velocity. | ✅ |
