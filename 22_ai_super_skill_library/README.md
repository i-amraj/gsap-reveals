This is the ultimate reference library for the AI. It contains advanced, Awwwards-level snippets combining GSAP with WebGL (Three.js), Canvas, Lottie, and complex math.

| 03 | `magnetic_button` | Mouse-move distance calculation for a sticky UI magnetic pull. | ✅ |
