# Kinetic Typography Wheel
Constructs a 3D cylinder out of HTML text strings using `rotateX` and `translateZ` in CSS. GSAP runs two simultaneous animations: an infinite linear horizontal translation of the text (`xPercent: -50`), and a ScrollTrigger-scrubbed 3D `rotationX` of the entire parent container. This creates a mesmerizing, rolling kinetic text drum effect.
