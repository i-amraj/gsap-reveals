# 🏆 Project 6.2: Apple Product Launch (`20_apple_product_launch`)

This library provides 22 variations of Apple-style product launch scroll animations.
Apple's landing pages are famous for their heavily choreographed, scroll-scrubbed, pinned animations focusing on extreme product detail and hardware features.

## 🚀 How to Use
Navigate into any sub-directory and open `index.html` in your browser. Each directory contains a `prompt.md` which you can use to generate this exact effect in any AI.
