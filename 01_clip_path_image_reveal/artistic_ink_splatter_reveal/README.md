## 🧠 Core Canvas Ink Concept
- Mouse movement spawns `InkSplatter` particles with irregular splatter drop radius and sub-splatter dots.
- `imgCtx.globalCompositeOperation = 'destination-in'` clips HD image inside wet ink splatter shapes.
