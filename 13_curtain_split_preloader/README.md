# 🌟 Style 4.1: Curtain Split Preloaders (`13_curtain_split_preloader`)

This library focuses on creating the highly sought-after "Awwwards-style" preloader. It combines a clean 0-100% numerical counter with geometric curtain-splitting reveals (vertical, horizontal, diagonal, staggered) that seamlessly transition into the main hero section of the website.

## 📦 Sub-Demos (Currently 4)

| # | Module Name | Description | Status |
|---|---|---|---|
| 01 | `basic_vertical_curtain_split` | A clean 0-100% counter. At 100%, the screen splits in half vertically (top up, bottom down) to reveal the hero section. | ✅ |
| 02 | `horizontal_sliding_doors` | The preloader acts as two massive sliding doors that pull apart left and right once the counter hits 100%. | ✅ |
| 03 | `diagonal_slice_reveal` | Uses CSS `clip-path` to slice the preloader diagonally, creating an aggressive, angular split reveal. | ✅ |
| 04 | `multi_column_blinds_split` | The preloader consists of multiple vertical columns that slide up in a staggered timeline, acting like window blinds. | ✅ |

## 🚀 How to Use
Navigate into any sub-directory and open `index.html` in your browser. Each directory contains a `prompt.md` which you can use to generate this exact effect in any AI.
