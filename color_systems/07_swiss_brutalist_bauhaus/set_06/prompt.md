# AI Design Prompt: Ultramarine Bold (Swiss Brutalist Bauhaus)

```markdown
Design a modern, high-impact web interface using the 'Ultramarine Bold' color palette from the Swiss Brutalist Bauhaus system.

Color Token Hierarchy:
- --bg: #f8fafc (Main page background canvas)
- --surface: #ffffff (Card containers, navigation bars, bento cells)
- --surface-hover: #f1f5f9 (Card hover states)
- --border: #1e3a8a (Subtle divider and container borders)
- --primary: #1d4ed8 (Primary CTA buttons, active state indicators, key highlights)
- --primary-hover: #1e40af (Button hover state)
- --secondary: #ea580c (Secondary action badges, supporting graphics)
- --accent: #000000 (Accent notifications, status chips, highlight pings)
- --text: #0f172a (Primary heading and body typography)
- --text-muted: #475569 (Subtitles, metadata, form labels)
- --glow: rgba(29, 78, 216, 0.25) (Radial ambient drop shadows and neon backlights)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
