# AI Design Prompt: Bauhaus Primary (Swiss Brutalist Bauhaus)

```markdown
Design a modern, high-impact web interface using the 'Bauhaus Primary' color palette from the Swiss Brutalist Bauhaus system.

Color Token Hierarchy:
- --bg: #ffffff (Main page background canvas)
- --surface: #f8fafc (Card containers, navigation bars, bento cells)
- --surface-hover: #f1f5f9 (Card hover states)
- --border: #000000 (Subtle divider and container borders)
- --primary: #e11d48 (Primary CTA buttons, active state indicators, key highlights)
- --primary-hover: #be123c (Button hover state)
- --secondary: #1d4ed8 (Secondary action badges, supporting graphics)
- --accent: #facc15 (Accent notifications, status chips, highlight pings)
- --text: #000000 (Primary heading and body typography)
- --text-muted: #475569 (Subtitles, metadata, form labels)
- --glow: rgba(225, 29, 72, 0.25) (Radial ambient drop shadows and neon backlights)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
