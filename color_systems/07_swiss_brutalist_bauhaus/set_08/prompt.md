# AI Design Prompt: De Stijl Quad (Swiss Brutalist Bauhaus)

```markdown
Design a modern, high-impact web interface using the 'De Stijl Quad' color palette from the Swiss Brutalist Bauhaus system.

Color Token Hierarchy:
- --bg: #fafafa (Main page background canvas)
- --surface: #ffffff (Card containers, navigation bars, bento cells)
- --surface-hover: #f4f4f5 (Card hover states)
- --border: #000000 (Subtle divider and container borders)
- --primary: #dc2626 (Primary CTA buttons, active state indicators, key highlights)
- --primary-hover: #b91c1c (Button hover state)
- --secondary: #2563eb (Secondary action badges, supporting graphics)
- --accent: #facc15 (Accent notifications, status chips, highlight pings)
- --text: #000000 (Primary heading and body typography)
- --text-muted: #262626 (Subtitles, metadata, form labels)
- --glow: rgba(220, 38, 38, 0.25) (Radial ambient drop shadows and neon backlights)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
