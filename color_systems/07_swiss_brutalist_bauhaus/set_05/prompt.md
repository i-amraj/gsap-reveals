# AI Design Prompt: Modernist Yellow (Swiss Brutalist Bauhaus)

```markdown
Design a modern, high-impact web interface using the 'Modernist Yellow' color palette from the Swiss Brutalist Bauhaus system.

Color Token Hierarchy:
- --bg: #ffffff (Main page background canvas)
- --surface: #fefce8 (Card containers, navigation bars, bento cells)
- --surface-hover: #fef9c3 (Card hover states)
- --border: #000000 (Subtle divider and container borders)
- --primary: #ca8a04 (Primary CTA buttons, active state indicators, key highlights)
- --primary-hover: #a16207 (Button hover state)
- --secondary: #000000 (Secondary action badges, supporting graphics)
- --accent: #2563eb (Accent notifications, status chips, highlight pings)
- --text: #000000 (Primary heading and body typography)
- --text-muted: #52525b (Subtitles, metadata, form labels)
- --glow: rgba(202, 138, 4, 0.25) (Radial ambient drop shadows and neon backlights)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
