# AI Design Prompt: Zurich Concrete (Swiss Brutalist Bauhaus)

```markdown
Design a modern, high-impact web interface using the 'Zurich Concrete' color palette from the Swiss Brutalist Bauhaus system.

Color Token Hierarchy:
- --bg: #f4f4f5 (Main page background canvas)
- --surface: #ffffff (Card containers, navigation bars, bento cells)
- --surface-hover: #e4e4e7 (Card hover states)
- --border: #18181b (Subtle divider and container borders)
- --primary: #09090b (Primary CTA buttons, active state indicators, key highlights)
- --primary-hover: #27272a (Button hover state)
- --secondary: #ef4444 (Secondary action badges, supporting graphics)
- --accent: #3b82f6 (Accent notifications, status chips, highlight pings)
- --text: #09090b (Primary heading and body typography)
- --text-muted: #52525b (Subtitles, metadata, form labels)
- --glow: rgba(9, 9, 11, 0.2) (Radial ambient drop shadows and neon backlights)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
