# AI Design Prompt: International Blue (Swiss Brutalist Bauhaus)

```markdown
Design a modern, high-impact web interface using the 'International Blue' color palette from the Swiss Brutalist Bauhaus system.

Color Token Hierarchy:
- --bg: #ffffff (Main page background canvas)
- --surface: #f8fafc (Card containers, navigation bars, bento cells)
- --surface-hover: #eff6ff (Card hover states)
- --border: #000000 (Subtle divider and container borders)
- --primary: #2563eb (Primary CTA buttons, active state indicators, key highlights)
- --primary-hover: #1d4ed8 (Button hover state)
- --secondary: #000000 (Secondary action badges, supporting graphics)
- --accent: #dc2626 (Accent notifications, status chips, highlight pings)
- --text: #000000 (Primary heading and body typography)
- --text-muted: #334155 (Subtitles, metadata, form labels)
- --glow: rgba(37, 99, 235, 0.25) (Radial ambient drop shadows and neon backlights)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
