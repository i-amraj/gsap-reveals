# AI Design Prompt: Constructivist Red (Swiss Brutalist Bauhaus)

```markdown
Design a modern, high-impact web interface using the 'Constructivist Red' color palette from the Swiss Brutalist Bauhaus system.

Color Token Hierarchy:
- --bg: #fdfbf7 (Main page background canvas)
- --surface: #ffffff (Card containers, navigation bars, bento cells)
- --surface-hover: #f7f2ea (Card hover states)
- --border: #000000 (Subtle divider and container borders)
- --primary: #b91c1c (Primary CTA buttons, active state indicators, key highlights)
- --primary-hover: #991b1b (Button hover state)
- --secondary: #000000 (Secondary action badges, supporting graphics)
- --accent: #475569 (Accent notifications, status chips, highlight pings)
- --text: #000000 (Primary heading and body typography)
- --text-muted: #44403c (Subtitles, metadata, form labels)
- --glow: rgba(185, 28, 28, 0.25) (Radial ambient drop shadows and neon backlights)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
