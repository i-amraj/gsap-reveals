# AI Design Prompt: Akihabara Glow (Tokyo Night Synthwave)

```markdown
Design a modern, high-impact web interface using the 'Akihabara Glow' color palette from the Tokyo Night Synthwave system.

Color Token Hierarchy:
- --bg: #0a0614 (Main page background canvas)
- --surface: #1a1030 (Card containers, navigation bars, bento cells)
- --surface-hover: #261747 (Card hover states)
- --border: #3b246e (Subtle divider and container borders)
- --primary: #facc15 (Primary CTA buttons, active state indicators, key highlights)
- --primary-hover: #fde047 (Button hover state)
- --secondary: #ec4899 (Secondary action badges, supporting graphics)
- --accent: #9333ea (Accent notifications, status chips, highlight pings)
- --text: #ffffff (Primary heading and body typography)
- --text-muted: #cbd5e1 (Subtitles, metadata, form labels)
- --glow: rgba(250, 204, 21, 0.4) (Radial ambient drop shadows and neon backlights)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
