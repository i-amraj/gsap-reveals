# AI Design Prompt: Bioluminescent AI Light (AI Generative Future Chroma)

```markdown
Design a modern, high-impact web interface using the 'Bioluminescent AI Light' color palette from the AI Generative Future Chroma system.

Color Token Hierarchy:
- --bg: #f8faff (Main page background canvas)
- --surface: #ffffff (Card containers, navigation bars, bento cells)
- --surface-hover: #f0f4ff (Card hover states)
- --border: #dbe4fe (Subtle divider and container borders)
- --primary: #2563eb (Primary CTA buttons, active state indicators, key highlights)
- --primary-hover: #1d4ed8 (Button hover state)
- --secondary: #7c3aed (Secondary action badges, supporting graphics)
- --accent: #06b6d4 (Accent notifications, status chips, highlight pings)
- --text: #0f172a (Primary heading and body typography)
- --text-muted: #475569 (Subtitles, metadata, form labels)
- --glow: rgba(37, 99, 235, 0.25) (Radial ambient drop shadows and neon backlights)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
