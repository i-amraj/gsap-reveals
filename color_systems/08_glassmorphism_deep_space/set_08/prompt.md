# AI Design Prompt: Galactic Core (Glassmorphism Deep Space)

```markdown
Design a modern, high-impact web interface using the 'Galactic Core' color palette from the Glassmorphism Deep Space system.

Color Token Hierarchy:

- --surface: #170a29 (Card containers, navigation bars, bento cells)

- --primary-hover: #f43f5e (Button hover state)

- --accent: #fde047 (Accent notifications, status chips, highlight pings)
- --text: #fff1f2 (Primary heading and body typography)
- --text-muted: #fbcfe8 (Subtitles, metadata, form labels)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
```
