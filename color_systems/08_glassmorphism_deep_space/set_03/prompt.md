```markdown
Design a modern, high-impact web interface using the 'Starlight Void' color palette from the Glassmorphism Deep Space system.

- --bg: #000000 (Main page background canvas)
- --surface: #111116 (Card containers, navigation bars, bento cells)
- --surface-hover: #1a1a24 (Card hover states)

- --primary-hover: #e2e8f0 (Button hover state)

- --accent: #a855f7 (Accent notifications, status chips, highlight pings)
- --text: #ffffff (Primary heading and body typography)
- --text-muted: #94a3b8 (Subtitles, metadata, form labels)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
