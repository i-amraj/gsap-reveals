```markdown
Design a modern, high-impact web interface using the 'Care & Wellness' color palette from the Clinical Clean Healthtech system.

Color Token Hierarchy:
- --bg: #fdfcfa (Main page background canvas)
- --surface: #ffffff (Card containers, navigation bars, bento cells)
- --surface-hover: #f8f5ee (Card hover states)

- --primary-hover: #115e59 (Button hover state)

- --accent: #f59e0b (Accent notifications, status chips, highlight pings)
- --text: #134e4a (Primary heading and body typography)
- --text-muted: #57534e (Subtitles, metadata, form labels)
- --glow: rgba(15, 118, 110, 0.2) (Radial ambient drop shadows and neon backlights)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
