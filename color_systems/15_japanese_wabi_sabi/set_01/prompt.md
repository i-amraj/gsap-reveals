# AI Design Prompt: Sumi Ink & Linen (Japanese Wabi-Sabi)

```markdown
Design a modern, high-impact web interface using the 'Sumi Ink & Linen' color palette from the Japanese Wabi-Sabi system.

Color Token Hierarchy:
- --bg: #fcfbf7 (Main page background canvas)
- --surface: #ffffff (Card containers, navigation bars, bento cells)
- --surface-hover: #f5f3eb (Card hover states)
- --border: #e5e2d5 (Subtle divider and container borders)
- --primary: #1c1917 (Primary CTA buttons, active state indicators, key highlights)
- --primary-hover: #0c0a09 (Button hover state)
- --secondary: #78716c (Secondary action badges, supporting graphics)
- --accent: #dc2626 (Accent notifications, status chips, highlight pings)
- --text: #1c1917 (Primary heading and body typography)
- --text-muted: #57534e (Subtitles, metadata, form labels)
- --glow: rgba(28, 25, 23, 0.2) (Radial ambient drop shadows and neon backlights)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
