# AI Design Prompt: Kintsugi Gold Fracture (Japanese Wabi-Sabi)

```markdown
Design a modern, high-impact web interface using the 'Kintsugi Gold Fracture' color palette from the Japanese Wabi-Sabi system.

Color Token Hierarchy:
- --bg: #0e0e11 (Main page background canvas)
- --surface: #1a1a21 (Card containers, navigation bars, bento cells)
- --surface-hover: #262630 (Card hover states)
- --border: #373745 (Subtle divider and container borders)
- --primary: #f59e0b (Primary CTA buttons, active state indicators, key highlights)
- --primary-hover: #fbbf24 (Button hover state)
- --secondary: #fafaf9 (Secondary action badges, supporting graphics)
- --accent: #d97706 (Accent notifications, status chips, highlight pings)
- --text: #ffffff (Primary heading and body typography)
- --text-muted: #a8a29e (Subtitles, metadata, form labels)
- --glow: rgba(245, 158, 11, 0.4) (Radial ambient drop shadows and neon backlights)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
