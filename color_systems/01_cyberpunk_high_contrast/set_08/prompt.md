# AI Design Prompt: Cyber Chrome (Cyberpunk High Contrast)

```markdown
Design a modern, high-impact web interface using the 'Cyber Chrome' color palette from the Cyberpunk High Contrast system.

Color Token Hierarchy:
- --bg: #090d16 (Main page background canvas)
- --surface: #131b2e (Card containers, navigation bars, bento cells)
- --surface-hover: #1b2640 (Card hover states)
- --border: #243456 (Subtle divider and container borders)
- --primary: #e2e8f0 (Primary CTA buttons, active state indicators, key highlights)
- --primary-hover: #ffffff (Button hover state)
- --secondary: #2563eb (Secondary action badges, supporting graphics)
- --accent: #f97316 (Accent notifications, status chips, highlight pings)
- --text: #ffffff (Primary heading and body typography)
- --text-muted: #94a3b8 (Subtitles, metadata, form labels)
- --glow: rgba(226, 232, 240, 0.35) (Radial ambient drop shadows and neon backlights)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
