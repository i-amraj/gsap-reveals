# AI Design Prompt: Hot Overdrive (Cyberpunk High Contrast)

```markdown
Design a modern, high-impact web interface using the 'Hot Overdrive' color palette from the Cyberpunk High Contrast system.

- --accent: #06b6d4 (Accent notifications, status chips, highlight pings)
- --text: #f9fafb (Primary heading and body typography)
- --text-muted: #9ca3af (Subtitles, metadata, form labels)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.

- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
