# AI Design Prompt: Editorial 1960 (Luxury Editorial Monochrome)

```markdown
Design a modern, high-impact web interface using the 'Editorial 1960' color palette from the Luxury Editorial Monochrome system.

Color Token Hierarchy:
- --bg: #000000 (Main page background canvas)
- --surface: #121212 (Card containers, navigation bars, bento cells)
- --surface-hover: #1c1c1c (Card hover states)
- --border: #282828 (Subtle divider and container borders)
- --primary: #ffffff (Primary CTA buttons, active state indicators, key highlights)
- --primary-hover: #e5e5e5 (Button hover state)
- --secondary: #a3a3a3 (Secondary action badges, supporting graphics)
- --accent: #ef4444 (Accent notifications, status chips, highlight pings)
- --text: #ffffff (Primary heading and body typography)
- --text-muted: #a3a3a3 (Subtitles, metadata, form labels)
- --glow: rgba(255, 255, 255, 0.3) (Radial ambient drop shadows and neon backlights)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
