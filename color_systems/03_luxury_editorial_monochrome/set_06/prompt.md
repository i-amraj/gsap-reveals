# AI Design Prompt: Midnight Velvet (Luxury Editorial Monochrome)

```markdown
Design a modern, high-impact web interface using the 'Midnight Velvet' color palette from the Luxury Editorial Monochrome system.

Color Token Hierarchy:
- --bg: #030712 (Main page background canvas)
- --surface: #0d1326 (Card containers, navigation bars, bento cells)
- --surface-hover: #16203d (Card hover states)
- --border: #1f2c52 (Subtle divider and container borders)
- --primary: #c084fc (Primary CTA buttons, active state indicators, key highlights)
- --primary-hover: #d8b4fe (Button hover state)
- --secondary: #e2e8f0 (Secondary action badges, supporting graphics)
- --accent: #38bdf8 (Accent notifications, status chips, highlight pings)
- --text: #f8fafc (Primary heading and body typography)
- --text-muted: #94a3b8 (Subtitles, metadata, form labels)
- --glow: rgba(192, 132, 252, 0.35) (Radial ambient drop shadows and neon backlights)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
