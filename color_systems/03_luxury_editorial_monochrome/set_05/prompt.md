# AI Design Prompt: Parisian Cashmere (Luxury Editorial Monochrome)

```markdown
Design a modern, high-impact web interface using the 'Parisian Cashmere' color palette from the Luxury Editorial Monochrome system.

Color Token Hierarchy:
- --bg: #fcfbf9 (Main page background canvas)
- --surface: #ffffff (Card containers, navigation bars, bento cells)
- --surface-hover: #f7f5f0 (Card hover states)
- --border: #ebe7df (Subtle divider and container borders)
- --primary: #292524 (Primary CTA buttons, active state indicators, key highlights)
- --primary-hover: #1c1917 (Button hover state)
- --secondary: #78716c (Secondary action badges, supporting graphics)
- --accent: #b45309 (Accent notifications, status chips, highlight pings)
- --text: #1c1917 (Primary heading and body typography)
- --text-muted: #78716c (Subtitles, metadata, form labels)
- --glow: rgba(41, 37, 36, 0.2) (Radial ambient drop shadows and neon backlights)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
