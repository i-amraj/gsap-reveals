# AI Design Prompt: Vogue Espresso (Luxury Editorial Monochrome)

```markdown
Design a modern, high-impact web interface using the 'Vogue Espresso' color palette from the Luxury Editorial Monochrome system.

Color Token Hierarchy:
- --bg: #1c1917 (Main page background canvas)
- --surface: #292524 (Card containers, navigation bars, bento cells)
- --surface-hover: #3c3633 (Card hover states)
- --border: #44403c (Subtle divider and container borders)
- --primary: #fafaf9 (Primary CTA buttons, active state indicators, key highlights)
- --primary-hover: #ffffff (Button hover state)
- --secondary: #d6d3d1 (Secondary action badges, supporting graphics)
- --accent: #ca8a04 (Accent notifications, status chips, highlight pings)
- --text: #ffffff (Primary heading and body typography)
- --text-muted: #a8a29e (Subtitles, metadata, form labels)
- --glow: rgba(250, 250, 249, 0.25) (Radial ambient drop shadows and neon backlights)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
