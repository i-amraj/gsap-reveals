# AI Design Prompt: Onyx & Champagne (Luxury Editorial Monochrome)

```markdown
Design a modern, high-impact web interface using the 'Onyx & Champagne' color palette from the Luxury Editorial Monochrome system.

Color Token Hierarchy:
- --bg: #0a0a0a (Main page background canvas)
- --surface: #141414 (Card containers, navigation bars, bento cells)
- --surface-hover: #1f1f1f (Card hover states)
- --border: #2a2a2a (Subtle divider and container borders)
- --primary: #d4af37 (Primary CTA buttons, active state indicators, key highlights)
- --primary-hover: #f5d061 (Button hover state)
- --secondary: #f5f5f4 (Secondary action badges, supporting graphics)
- --accent: #e5e5e5 (Accent notifications, status chips, highlight pings)
- --text: #fafaf9 (Primary heading and body typography)
- --text-muted: #a8a29e (Subtitles, metadata, form labels)
- --glow: rgba(212, 175, 55, 0.35) (Radial ambient drop shadows and neon backlights)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
