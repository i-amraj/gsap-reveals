# AI Design Prompt: Tuscan Marble (Luxury Editorial Monochrome)

```markdown
Design a modern, high-impact web interface using the 'Tuscan Marble' color palette from the Luxury Editorial Monochrome system.

Color Token Hierarchy:
- --bg: #fafafa (Main page background canvas)
- --surface: #ffffff (Card containers, navigation bars, bento cells)
- --surface-hover: #f4f4f5 (Card hover states)
- --border: #e4e4e7 (Subtle divider and container borders)
- --primary: #15803d (Primary CTA buttons, active state indicators, key highlights)
- --primary-hover: #166534 (Button hover state)
- --secondary: #b45309 (Secondary action badges, supporting graphics)
- --accent: #475569 (Accent notifications, status chips, highlight pings)
- --text: #09090b (Primary heading and body typography)
- --text-muted: #52525b (Subtitles, metadata, form labels)
- --glow: rgba(21, 128, 61, 0.2) (Radial ambient drop shadows and neon backlights)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
