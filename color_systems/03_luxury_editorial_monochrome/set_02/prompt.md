# AI Design Prompt: Platinum Minimal (Luxury Editorial Monochrome)

```markdown
Design a modern, high-impact web interface using the 'Platinum Minimal' color palette from the Luxury Editorial Monochrome system.

Color Token Hierarchy:
- --bg: #ffffff (Main page background canvas)
- --surface: #fafafa (Card containers, navigation bars, bento cells)
- --surface-hover: #f4f4f5 (Card hover states)
- --border: #e4e4e7 (Subtle divider and container borders)
- --primary: #18181b (Primary CTA buttons, active state indicators, key highlights)
- --primary-hover: #09090b (Button hover state)
- --secondary: #71717a (Secondary action badges, supporting graphics)
- --accent: #a1a1aa (Accent notifications, status chips, highlight pings)
- --text: #09090b (Primary heading and body typography)
- --text-muted: #71717a (Subtitles, metadata, form labels)
- --glow: rgba(24, 24, 27, 0.2) (Radial ambient drop shadows and neon backlights)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
