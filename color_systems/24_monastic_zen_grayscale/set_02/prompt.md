# AI Design Prompt: Gallery White Minimal (Monastic Zen Grayscale)

```markdown
Design a modern, high-impact web interface using the 'Gallery White Minimal' color palette from the Monastic Zen Grayscale system.

Color Token Hierarchy:
- --bg: #ffffff (Main page background canvas)
- --surface: #f4f4f5 (Card containers, navigation bars, bento cells)
- --surface-hover: #e4e4e7 (Card hover states)
- --border: #d4d4d8 (Subtle divider and container borders)
- --primary: #09090b (Primary CTA buttons, active state indicators, key highlights)
- --primary-hover: #18181b (Button hover state)
- --secondary: #52525b (Secondary action badges, supporting graphics)
- --accent: #71717a (Accent notifications, status chips, highlight pings)
- --text: #09090b (Primary heading and body typography)
- --text-muted: #71717a (Subtitles, metadata, form labels)
- --glow: rgba(9, 9, 11, 0.15) (Radial ambient drop shadows and neon backlights)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
