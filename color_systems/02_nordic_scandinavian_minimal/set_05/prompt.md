# AI Design Prompt: Arctic Cloud (Nordic Scandinavian Minimal)

```markdown
Design a modern, high-impact web interface using the 'Arctic Cloud' color palette from the Nordic Scandinavian Minimal system.

Color Token Hierarchy:
- --bg: #f1f5f9 (Main page background canvas)
- --surface: #ffffff (Card containers, navigation bars, bento cells)
- --surface-hover: #e2e8f0 (Card hover states)
- --border: #cbd5e1 (Subtle divider and container borders)
- --primary: #475569 (Primary CTA buttons, active state indicators, key highlights)
- --primary-hover: #334155 (Button hover state)
- --secondary: #0ea5e9 (Secondary action badges, supporting graphics)
- --accent: #64748b (Accent notifications, status chips, highlight pings)
- --text: #0f172a (Primary heading and body typography)
- --text-muted: #64748b (Subtitles, metadata, form labels)
- --glow: rgba(71, 85, 105, 0.2) (Radial ambient drop shadows and neon backlights)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
