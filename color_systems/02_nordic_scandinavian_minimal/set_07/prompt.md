# AI Design Prompt: Oslo Fog (Nordic Scandinavian Minimal)

```markdown
Design a modern, high-impact web interface using the 'Oslo Fog' color palette from the Nordic Scandinavian Minimal system.

Color Token Hierarchy:
- --bg: #f3f4f6 (Main page background canvas)
- --surface: #ffffff (Card containers, navigation bars, bento cells)
- --surface-hover: #e5e7eb (Card hover states)
- --border: #d1d5db (Subtle divider and container borders)
- --primary: #374151 (Primary CTA buttons, active state indicators, key highlights)
- --primary-hover: #1f2937 (Button hover state)
- --secondary: #2563eb (Secondary action badges, supporting graphics)
- --accent: #f59e0b (Accent notifications, status chips, highlight pings)
- --text: #111827 (Primary heading and body typography)
- --text-muted: #6b7280 (Subtitles, metadata, form labels)
- --glow: rgba(55, 65, 81, 0.2) (Radial ambient drop shadows and neon backlights)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
