# AI Design Prompt: Fjord Ice Light (Nordic Scandinavian Minimal)

```markdown
Design a modern, high-impact web interface using the 'Fjord Ice Light' color palette from the Nordic Scandinavian Minimal system.

Color Token Hierarchy:
- --bg: #f8fafc (Main page background canvas)
- --surface: #ffffff (Card containers, navigation bars, bento cells)

- --primary: #0284c7 (Primary CTA buttons, active state indicators, key highlights)
- --primary-hover: #0369a1 (Button hover state)
- --secondary: #0c4a6e (Secondary action badges, supporting graphics)
- --accent: #38bdf8 (Accent notifications, status chips, highlight pings)
- --text: #0f172a (Primary heading and body typography)
- --text-muted: #64748b (Subtitles, metadata, form labels)
- --glow: rgba(2, 132, 199, 0.2) (Radial ambient drop shadows and neon backlights)

Typography & Aesthetic Guidelines:
- Font pairing: 'Space Grotesk' for bold editorial headings + 'Plus Jakarta Sans' for clean UI body.
- Glassmorphism: backdrop-filter: blur(20px) with 1px solid var(--border).
- Micro-interactions: Elevate cards by translateY(-4px) and apply box-shadow with var(--glow).
```
