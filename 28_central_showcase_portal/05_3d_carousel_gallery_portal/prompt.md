# AI Prompt: 3D Rotating Cylinder Carousel Showcase Portal

```markdown
Build a 3D rotating cylinder showcase gallery using CSS 3D perspective and GSAP.

Key Requirements:
1. 3D Cylindrical Geometry:
   - Calculate equidistant radial angles around Y axis (360 / N degrees).
   - Position cards radially outwards in 3D space using rotateY and translateZ(radius).
2. Smooth Orbit Navigation:
   - Rotate the parent carousel ring around the Y-axis smoothly to bring selected cards forward.
   - Support previous/next buttons and left/right keyboard arrow keys.
   - Mirrored floor reflection gradient positioned below the 3D ring.
```
