# AI Prompt: Retro Arcade Cabinet Showcase Portal

```markdown
Build a nostalgic 80s/90s retro arcade machine cabinet UI with CRT scanlines and procedural 8-bit sound synthesis using GSAP 3 and Web Audio API.

Key Requirements:
1. Arcade Cabinet Aesthetics:
   - Pixel art font ('Press Start 2P'), backlit marquee header, curved CRT monitor with scanlines.
   - Physical control deck with D-pad up/down buttons, "INSERT 25¢ COIN" button, and big START button.
2. Web Audio 8-bit Synthesis:
   - Insert Coin: Procedural dual-frequency square wave jump (B5 988Hz to E6 1319Hz) with exponential tail decay.
   - Menu Blip: Rapid frequency chirp (440Hz to 880Hz) on stage selection change.
3. Keyboard & Control Binding:
   - Up/Down arrows navigate stage list with animated pixel cursor.
   - Enter or Spacebar launches the selected stage.
```
