# AI Prompt: Split View IDE Component Sandbox

```markdown
Build a CodePen/Webflow style split-screen sandbox IDE portal with responsive viewport framing and live iframe preview.

Key Requirements:
1. Split-Screen Layout:
   - Left sidebar with component tree explorer and syntax-highlighted code snippet box with a copy button.
   - Right main area with top navigation toolbar and responsive iframe preview canvas.
2. Device Viewport Switching:
   - Toggle buttons for Desktop (100%), Tablet (768px), and Mobile (390px) with smooth CSS width transition.
3. Component Switcher:
   - Selecting a component updates the live iframe, title, code snippet, and link with a subtle GSAP fade-in.
```
