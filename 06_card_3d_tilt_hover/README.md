# Style 2.2: Interactive 3D Perspective Tilt Hover (`06_card_3d_tilt_hover`)

This module demonstrates how to create highly interactive, premium 3D card tilt effects using GSAP and mouse tracking.

## 📦 Sub-Demos (22/22)

| # | Module Name | Description | Status |
|---|---|---|---|
| 01 | `basic_3d_tilt` | Simple X/Y rotation based on mouse coordinates relative to the card's center. | ✅ |

| 03 | `floating_elements_tilt` | Children with `translateZ` pop out of the card in true 3D space during the tilt. | ✅ |

## 🚀 How to Use
Navigate into any sub-directory and open `index.html` in your browser. Each directory contains a `prompt.md` which you can use to generate this exact effect in any AI.
