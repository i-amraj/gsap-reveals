# Green Sock Hero Morph
Replicates the bouncy, highly elastic nature of the official GSAP homepage. Uses standard GSAP `attr` animation to mutate SVG path data (simulating MorphSVG), combined with `ease: "bounce.out"` and `ease: "elastic.out(1, 0.3)"` to create the playful, "physics-based" feel that GreenSock is famous for.
