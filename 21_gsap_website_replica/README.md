# 🏆 Project 6.3: GSAP Website Replica (`21_gsap_website_replica`)

This library provides 22 variations that replicate the masterclass animation techniques found on the official GreenSock (GSAP) website.
This focuses on dark mode aesthetics, vivid neon green highlights, complex SVG manipulation, and demonstrating the capabilities of various GSAP plugins (simulated or real).

## 🚀 How to Use
Navigate into any sub-directory and open `index.html` in your browser. Each directory contains a `prompt.md` which you can use to generate this exact effect in any AI.
