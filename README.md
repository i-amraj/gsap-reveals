## 🔥 Key Features

- ⚡ **60FPS Offscreen Compositing Engine**: Utilizes offscreen mask canvas architecture with `destination-in` global composite operations for smooth rendering.
- 🎨 **16 Creative Visual Reveal Styles**: Ranging from fluid smoke and water ripples to cyberpunk matrices, shattered ice, and Japanese watercolor splatters.
- 🤖 **Standalone AI Master Prompts (`prompt.md`)**: Every folder contains a copy-pasteable prompt file to generate or integrate the exact effect using AI agents (Antigravity, ChatGPT, Claude).
- 📱 **Fully Responsive & Dual Input**: Optimized for high DPI displays with support for mouse cursor velocity, clicks, and touch gestures.
- 📦 **Zero External Asset Dependencies**: Built with modular HTML5, CSS3, pure JS particle engines, and GSAP 3.12.

## 💡 How to Use the AI Prompts (`prompt.md`)

Each subfolder contains a dedicated `prompt.md` file designed for direct copy-pasting into AI coding assistants (Antigravity, ChatGPT, Claude, Cursor):

1. Navigate to any demo subfolder (e.g., `01_clip_path_image_reveal/retro_pixelate_glitch_reveal/`).
2. Open **`prompt.md`**.
3. Copy the prompt block and paste it into your AI assistant.
4. The AI will generate or adapt that exact effect for your custom website layout!
