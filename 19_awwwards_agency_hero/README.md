# 🏆 Project 6.1: Awwwards Agency Hero (`19_awwwards_agency_hero`)

This library provides 22 variations of "Awwwards-winning" modern creative agency Hero sections.
These templates synthesize the animation techniques learned in previous modules (SplitText, ClipPath, ScrollTrigger, Mouse Parallax, etc.) into production-ready, full-page hero sections.

## 🚀 How to Use
Navigate into any sub-directory and open `index.html` in your browser. Each directory contains a `prompt.md` which you can use to generate this exact effect in any AI.
